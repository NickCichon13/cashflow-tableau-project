# Corprate finance optimization dashboard

* python, SQL, and Tableau project

## Overview

This project analyzes Accounts Receivable (A/R) and Accounts Payable (A/P) data to calculate key performance indicators (KPIs) that measure operational efficiency.

The KPIs include **Days Sales Outstanding** (DSO), **Days Payable Outstanding** (DPO), and the **Cash Conversion Cycle** (CCC).

By evaluating these metrics, we can identify inefficiencies within A/R and A/P processes and highlight opportunities to optimize cash flow. Using Tableau’s visualization capabilities, the project presents these insights through clear and interactive dashboards that make it easy to pinpoint areas needing improvement.

## Tech Stack

**Python** - Data clenzing and KPI calculation
**Postgresql**  - Data storage and querying
**Tableau** - Interactive data vizzulation
